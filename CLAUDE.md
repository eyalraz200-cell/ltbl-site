# Let There Be Light — festival site

Desktop-only, single-page festival site built from Figma page הגשה 5
(file `vFkPM0DGEDXyeG1ijR4Rs2`, page node `12360:2`). Live on GitHub Pages from branch `feat/site`.
The full guide is the wiki in `docs/wiki/` (Home, Architecture, Scroll engine, Editing content, Testing, Deploy, Decisions).

## Commands
- Run: `python3 server.py` → http://localhost:8010
- Test everything: `./tools/test-all.sh` (needs the server running). Run before every commit.
- Regenerate the world after editing the generator: `python3 tools/gen-world.py --write`
- Deploy: `git push origin feat/site` (Pages rebuilds in about a minute)
- Debug flags: `?nointro`, `?notravel`

## How it works (short)
- The page never scrolls as a document. One pinned `#world` holds `.backdrop` (scenery, scaled to cover the window)
  and `.stage` (content, scaled to contain, no clip). Both use Figma's 1728×1117 coordinates verbatim.
- Every element carries `data-k` = its box in each of the nine Figma frames
  (hero, about, day2–day6, shabbat, footer). `js/scroll.js` scrubs one timeline between them; feel is the
  `MOTION` object there (Eyal's pick — see docs/wiki/Decisions.md).
- A piece with less than a fifth of its box inside the frame is "parked"; in a window of another shape it is pushed
  out by the margin so it never shows beside or below the frame. Rebuilt on every resize.
- `js/stage.js` scaler · `js/intro.js` once-on-load intro · `js/nav.js` day labels at the window top.

## Non-negotiables
- `#world` in `index.html` is GENERATED by `tools/gen-world.py`. Never hand-edit it — a regenerate overwrites it
  (this lost a scenery fix on 2026-10-01). Change the generator, `--write`, commit both.
- Run one Claude session on this repo at a time.
- Figma coordinates are copied verbatim, never eyeballed. Assets come only from Figma `download_assets`, compressed
  to WebP (1.5× placed size, q78), never edited or substituted. One copy of shared pieces in `assets/img/shared/`.
- Intro selectors must target the hero's own pieces: the footer has its own `.logo` and `.ticket`, and the sun is
  also a `.cloud`.
- No instant scroll jumps. Any programmatic scroll is animated, then `ScrollTrigger.refresh()`.
- Tuning by eye goes through a `compare/` or `manual/` harness from `~/.claude/templates/harness-panel.js`
  (`_debug-*`, git-ignored), baked as exact values, harness deleted.
- Vanilla HTML/CSS/JS + GSAP 3.12.5 from cdnjs. No framework, no Tailwind, no build step.
- Check a visual change at three window shapes: 1728×1117, wide (2560×1080), tall/thin (1100×1400).
- Don't reverse a decision in docs/wiki/Decisions.md without asking Eyal.
- Screen recordings / reference videos (`*.mov`, `*.mp4`) stay out of git.
