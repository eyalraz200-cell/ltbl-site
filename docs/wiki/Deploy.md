# Deploy

GitHub Pages serves the root of branch **`feat/site`** of `eyalraz200-cell/ltbl-site`.

```
git push origin feat/site
```

Pages rebuilds in about a minute: https://eyalraz200-cell.github.io/ltbl-site/

If `feat/site` is ever merged into `master`, switch the Pages source branch in the repo settings too.

Screen recordings and reference videos (`*.mov`, `*.mp4`) are git-ignored; keep them out of the repo.
