# Let There Be Light — Festival Site Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the desktop-only "Let There Be Light" festival site from the Figma page הגשה 5 as a real, scrolling, animated single page, in its own project folder, using the exact assets exported from Figma.

**Architecture:** One `index.html` with nine full-viewport `<section class="fold">`s. Every fold is laid out on a fixed 1728×1117 "stage" (the Figma frame size) that is scaled by JS to cover the viewport, so every Figma coordinate is used verbatim and nothing is re-flowed. GSAP + ScrollTrigger pins each fold and scrubs its choreography; a separate once-on-load timeline plays the five-step intro (סרטון 1–5). Assets are exported from Figma with the MCP `download_assets` tool, then compressed to WebP.

**Tech Stack:** Vanilla HTML/CSS/JS. GSAP 3 + ScrollTrigger from cdnjs. Python dev server (copy of Portfolio's `server.py`, threaded, serves `/__bus__` for the harness). `cwebp` for compression. No build step, no framework, no Tailwind.

**Spec:** This plan is the spec. Source of truth for visuals: Figma file `vFkPM0DGEDXyeG1ijR4Rs2`, page `12360:2` (הגשה 5). Decisions already made with Eyal in chat (2026-10-01):

- Stage size is exactly `1728 × 1117` CSS px. All positions from Figma are copied verbatim into `css/folds.css`; never eyeballed.
- Every image on the page is a file under `assets/img/`. No Figma asset URLs may remain in code (they expire in 7 days).

- Font stack is `"RFC Vintage Apothecary"`, `"Abyssinica SIL"`, `"Tanach"`. **None are installed on this Mac** (checked 2026-10-01). Task 1 resolves this before any fold is built.
- GSAP pinned at an exact version from cdnjs: `https://cdnjs.cloudflare.com/ajax/libs/gsap/3.12.5/gsap.min.js` and `.../3.12.5/ScrollTrigger.min.js`.
- No instant scroll jumps anywhere (harness rule in `~/.claude/CLAUDE.md`). Any programmatic scroll is animated and followed by `ScrollTrigger.refresh()`.
- Text in the page is the Figma copy verbatim, including the typo "Fruitfull".
- All animation respects `prefers-reduced-motion: reduce`: intro is skipped, folds render in their rest state.
- Target: 60fps on an M-series MacBook in Chrome at 1728×1117; total transfer under 15 MB after compression.

- [x] **Step 2: `js/stage.js`**

```js
(function(){
  const W = 1728, H = 1117;
  const root = document.documentElement;
  function compute(){
    // cover: scale so the stage fills both axes; overflow is clipped by .fold
    const s = Math.max(innerWidth / W, innerHeight / H);
    root.style.setProperty('--stage-scale', s.toFixed(4));
    return s;
  }
  let scale = compute();
  let raf = 0;
  addEventListener('resize', () => {
    cancelAnimationFrame(raf);
    raf = requestAnimationFrame(() => {
      scale = compute();
      if (window.ScrollTrigger) ScrollTrigger.refresh();
    });
  });
  window.LTBL = {
    stageScale: () => scale,
    isDesktop: () => matchMedia('(min-width:1024px)').matches,
    reducedMotion: () => matchMedia('(prefers-reduced-motion: reduce)').matches,
  };
})();
```

### Task 6: Scroll engine (pin + travel) on folds 1–2

**Files:**
- Create: `js/scroll.js`
- Modify: `css/base.css`

**Interfaces:**
- Consumes: `LTBL.introDone`, `.fold` sections in DOM order, `[data-travel]` elements.
- Produces: `LTBL.scrollTo(foldId)` (animated, then `ScrollTrigger.refresh()`), and one `ScrollTrigger` per fold with `id: fold.id`. Travel contract: an element with `data-travel="from-<fold>"` in fold B animates from the position of the element with the same `class` in fold A (converted into B's stage coordinates) to its own position while B pins. `data-travel="to-<fold>"` animates out towards the matching element in the next fold.

- [x] **Step 1: Write `js/scroll.js`**

```js
(async function(){
  if (!LTBL.isDesktop()) return;
  await LTBL.introDone;
  gsap.registerPlugin(ScrollTrigger);
  const folds = [...document.querySelectorAll('.fold')];
  const reduced = LTBL.reducedMotion();

  function restPos(el){ return { x: el.offsetLeft, y: el.offsetTop }; }
  function matchIn(fold, el){
    const key = [...el.classList].filter(c => c !== 'cutout' && !c.startsWith('hand--'))[0];
    return fold.querySelector('.' + key + (el.classList.contains('hand--left') ? '.hand--left' : el.classList.contains('hand--right') ? '.hand--right' : ''));
  }

  folds.forEach((fold, i) => {
    const stage = fold.querySelector('.stage');
    const tl = gsap.timeline({
      scrollTrigger: { id: fold.id, trigger: fold, start: 'top top', end: '+=100%', pin: true, scrub: reduced ? false : 0.6, anticipatePin: 1 }
    });
    if (reduced) return;

    // elements arriving from the previous fold
    stage.querySelectorAll('[data-travel^="from-"]').forEach(el => {
      const prev = folds[i-1]; if (!prev) return;
      const src = matchIn(prev, el); if (!src) return;
      const a = restPos(src), b = restPos(el);
      tl.fromTo(el, { x: a.x - b.x, y: a.y - b.y - 1117 }, { x: 0, y: 0, ease: 'none' }, 0);
    });
    // elements leaving towards the next fold
    stage.querySelectorAll('[data-travel^="to-"]').forEach(el => {
      const next = folds[i+1]; if (!next) return;
      const dst = matchIn(next, el); if (!dst) return;
      const a = restPos(el), b = restPos(dst);
      tl.to(el, { x: b.x - a.x, y: b.y - a.y + 1117, ease: 'none' }, 0.5);
    });
    // every other cutout drifts in gently
    stage.querySelectorAll('.cutout:not([data-travel])').forEach((el, k) => {
      tl.from(el, { y: 80, autoAlpha: 0, duration: 0.3, ease: 'power2.out' }, 0.05 * k);
    });
  });

  window.LTBL.scrollTo = id => {
    const st = ScrollTrigger.getById(id); if (!st) return;
    gsap.to(window, { scrollTo: st.start, duration: 1, ease: 'power2.inOut', onComplete: () => ScrollTrigger.refresh() });
  };
  addEventListener('load', () => ScrollTrigger.refresh());
})();
```
`scrollTo` on `window` needs the ScrollToPlugin: add `https://cdnjs.cloudflare.com/ajax/libs/gsap/3.12.5/ScrollToPlugin.min.js` to `index.html` and `gsap.registerPlugin(ScrollToPlugin)`.
